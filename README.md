# Analyse-actuarielle-des-taux-de-mortalit-et-des-primes-d-assurance
 Analyse actuarielle des taux de mortalité et des  primes d’assurance  Population française, 1970–2060
Ce projet présente une étude actuarielle sur la mortalité d’un portefeuille d’assurés français, dans le but d’évaluer la valeur actuelle probable (VAP) d’un produit de capital décès à prime annuelle.
L’analyse repose sur des données issues de la Human Mortality Database (HMD) et utilise le modèle stochastique de Lee-Carter (implémenté sous R via le package StMoMo) pour projeter les taux de mortalité futurs et calculer les primes équitables.

L’étude compare également les résultats entre hommes et femmes, met en évidence les écarts liés aux hypothèses de projection et propose une analyse de sensibilité sur le taux technique.
